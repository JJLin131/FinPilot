# 招商银行转账与电子回单规则

## 1. 适用范围

本文档适用于财资管理系统通过招商银行银企直连渠道发起的单笔转账、批量转账、工资代发、账户余额查询、交易状态查询、电子回单下载等业务。

## 2. 支持业务

招商银行渠道支持以下业务：

- 单笔转账
- 批量转账
- 快速转账
- 同行转账
- 跨行转账
- 工资代发
- 账户余额查询
- 交易状态查询
- 电子回单下载

## 3. 转账规则

### 3.1 单笔转账

规则：

- 单笔转账金额上限默认为 2000000 元。
- 支持同行和跨行转账。
- 支持快速转账模式。
- 转账用途不能为空。
- 单笔金额超过 1000000 元时，需要企业 UKey 或授权确认。
- 跨行转账需要校验收款账户名称。

### 3.2 快速转账

快速转账适用于小额高频付款场景。

规则：

- 单笔快速转账金额不得超过 500000 元。
- 快速转账适用于报销款、补贴款、小额供应商付款。
- 快速转账通常返回较明确的成功或失败状态。
- 快速转账失败后，可以重新发起付款。
- 快速转账不适用于大额采购付款。

### 3.3 批量转账

规则：

- 单批次最多支持 1000 笔。
- 批量转账需要上传标准模板。
- 批量转账中的失败明细不会生成电子回单。
- 如果批次部分成功，系统需要展示成功明细和失败明细。
- 用户可以基于失败明细重新发起补付。

### 3.4 工资代发

规则：

- 工资代发单批次最多支持 3000 笔。
- 工资代发必须经过工资发放审批流。
- 工资代发支持预约发放。
- 工资代发批次全部处理完成后，才能下载批量结果文件。

## 4. 状态查询规则

招商银行交易可能返回以下状态：

| 银行状态 | 系统状态 | 说明 |
|---|---|---|
| SUCCESS | 成功 | 交易成功 |
| FAILED | 失败 | 交易失败 |
| PENDING_CLEARING | 银行处理中 | 跨行交易待清算 |
| PROCESSING | 银行处理中 | 银行处理中 |
| NEED_AUTH | 待授权 | 需要企业授权确认 |

查询规则：

- 招商银行通常返回明确的成功或失败状态。
- 跨行交易可能返回待清算。
- 待清算状态需要继续查询。
- 建议每 2 分钟查询一次，最多查询 30 分钟。
- NEED_AUTH 状态下，需要企业完成 UKey 或授权确认。

## 5. 电子回单规则

招商银行电子回单规则：

- 单笔转账成功后一般可立即申请回单。
- 批量转账回单需要等待批次全部处理完成。
- 回单文件格式支持 PDF。
- 如果批次为部分成功，则只能对成功明细下载回单。
- 失败明细不生成电子回单。
- 回单重复下载时，系统优先返回已缓存文件。

## 6. 回单下载参数

下载招商银行电子回单时，系统需要提供以下参数：

| 参数 | 是否必填 | 说明 |
|---|---|---|
| 企业客户号 | 是 | 招商银行企业客户编号 |
| 付款账户 | 是 | 企业付款账号 |
| 交易流水号 | 是 | 银行返回的交易流水 |
| 交易日期 | 是 | 交易日期 |
| 回单类型 | 否 | 单笔回单或批量回单 |

## 7. 异常处理

### 7.1 待授权状态

如果银行返回 NEED_AUTH，系统应提示用户完成企业授权确认。未完成授权前，交易不得标记为成功。

### 7.2 待清算状态

如果跨行交易返回待清算，系统应继续查询，不允许重复提交。

### 7.3 部分成功状态

如果批量转账部分成功，系统应：

1. 展示成功明细。
2. 展示失败明细和失败原因。
3. 允许下载成功明细回单。
4. 允许失败明细重新提交。

## 8. 常见问答

### 问：招商银行 NEED_AUTH 是什么意思？

答：NEED_AUTH 表示该笔交易需要企业完成 UKey 或授权确认。授权完成后，系统才能继续查询最终状态。

### 问：招商银行快速转账适合哪些业务？

答：快速转账适合小额高频付款，例如员工报销、补贴、小额供应商付款，不适合大额采购付款。

### 问：招商银行部分成功可以下载回单吗？

答：可以，但只能下载成功明细的回单，失败明细不会生成回单。
