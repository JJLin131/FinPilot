# 工商银行转账与电子回单规则

## 1. 适用范围

本文档适用于财资管理系统通过工商银行银企直连渠道发起的单笔转账、批量转账、工资代发、余额查询、流水查询、电子回单下载等业务。

## 2. 支持业务

工商银行渠道支持以下业务：

- 单笔转账
- 批量转账
- 同行转账
- 跨行转账
- 工资代发
- 账户余额查询
- 交易流水查询
- 交易状态查询
- 电子回单下载

## 3. 转账规则

### 3.1 单笔转账

规则：

- 支持同行和跨行转账。
- 单笔转账最大金额默认为 5000000 元。
- 转账用途不能为空，最多 100 个字符。
- 跨行转账建议填写收款银行和开户支行。
- 工作日 09:00 至 17:00 支持实时处理。
- 17:00 后提交的跨行转账可能顺延至下一工作日。

### 3.2 批量转账

规则：

- 单批次最多支持 3000 笔明细。
- 单批次总金额不得超过企业批量付款限额。
- 批量文件必须通过系统格式校验。
- 批量转账提交后，银行先返回受理状态。
- 最终成功或失败结果需要通过状态查询接口获取。

### 3.3 工资代发

规则：

- 工资代发单批次最多支持 5000 笔。
- 工资代发需要使用工商银行代发接口。
- 工资代发不建议与普通采购付款混用。
- 工资批次提交后，银行返回批次流水号。
- 系统需要保存批次流水号，用于后续结果查询和回单下载。

## 4. 状态查询规则

工商银行交易提交后可能返回以下状态：

| 银行状态 | 系统状态 | 说明 |
|---|---|---|
| ACCEPTED | 银行处理中 | 银行已受理请求 |
| SUCCESS | 成功 | 交易已成功 |
| FAILED | 失败 | 交易失败 |
| PROCESSING | 银行处理中 | 银行仍在处理 |
| UNKNOWN | 待核查 | 状态未知，需要人工核查 |

查询规则：

- 银行受理后建议每 5 分钟查询一次。
- 最多自动查询 12 次。
- 超过 1 小时仍未返回最终状态时，系统标记为银行处理中。
- 银行返回未知状态时，应进入人工核查队列。
- 状态未明确成功前，不允许下载电子回单。

## 5. 电子回单规则

工商银行电子回单规则：

- 同行转账成功后通常 10 分钟内生成电子回单。
- 跨行转账成功后通常 30 分钟内生成电子回单。
- 批量转账需要按明细下载回单。
- 回单文件格式支持 PDF。
- 回单下载前必须确认交易状态为成功。
- 失败交易不生成电子回单。
- 银行处理中状态不允许下载回单。

## 6. 回单下载参数

下载工商银行电子回单时，系统需要提供以下参数：

| 参数 | 是否必填 | 说明 |
|---|---|---|
| 企业客户号 | 是 | 银行分配的企业客户编号 |
| 付款账号 | 是 | 企业付款账户 |
| 银行流水号 | 是 | 转账成功后的银行流水号 |
| 交易日期 | 是 | 交易发生日期 |
| 金额 | 是 | 交易金额 |
| 回单类型 | 否 | 单笔回单或批量回单 |

## 7. 异常处理

### 7.1 回单未生成

如果交易已经成功但回单未生成，系统应提示：

银行暂未生成电子回单，请稍后重试。

### 7.2 状态长时间处理中

如果交易长时间处于银行处理中，系统应：

1. 继续保留银行处理中状态。
2. 禁止用户重复提交同一笔交易。
3. 允许用户发起人工核查。
4. 记录最后一次查询时间和银行返回信息。

### 7.3 下载失败

如果回单下载失败，系统应：

1. 记录失败原因。
2. 支持用户手动重试。
3. 如果银行返回文件为空，则提示银行暂未生成回单。
4. 如果银行接口超时，则建议稍后重试。

## 8. 常见问答

### 问：工商银行跨行转账多久可以下载回单？

答：跨行转账成功后通常 30 分钟内生成电子回单。如果交易刚成功但回单不可下载，可以稍后重试。

### 问：工商银行返回 ACCEPTED 是成功吗？

答：不是。ACCEPTED 表示银行已经受理请求，但不代表最终成功。系统需要继续查询交易状态。

### 问：批量转账部分失败时是否能下载回单？

答：可以，但只能下载成功明细的回单，失败明细不会生成电子回单。
