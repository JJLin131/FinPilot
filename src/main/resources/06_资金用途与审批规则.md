# 企业资金用途与审批规则

## 1. 适用范围

本文档适用于财资管理系统中的付款审批、资金用途识别、预算控制和风险审批场景。

资金用途包括：

- 员工报销
- 工资发放
- 采购付款
- 供应商货款
- 备用金申请
- 差旅借款
- 税费缴纳
- 融资还款
- 内部资金调拨
- 对外投资付款

## 2. 通用审批原则

所有付款申请必须满足以下规则：

1. 付款申请必须由有权限的经办人提交。
2. 付款金额必须大于 0。
3. 付款账户必须为企业已授权账户。
4. 收款账户必须通过基础信息校验。
5. 超预算付款必须增加预算负责人审批。
6. 高风险付款需要财务总监或总经理审批。
7. 审批通过前不得发送银行。
8. 审批被驳回后，经办人可以修改后重新提交。
9. 审批通过后，如果修改付款金额、收款账户或付款用途，需要重新审批。
10. 银行发送前，系统必须校验账户余额和支付限额。

## 3. 报销付款审批规则

### 3.1 适用范围

报销付款适用于员工因差旅、办公采购、业务招待、交通通讯等产生的费用报销。

### 3.2 基础规则

- 报销申请必须关联报销单。
- 报销单必须包含发票或费用凭证。
- 报销金额不得超过已审批报销金额。
- 收款账户原则上必须为员工本人账户。
- 如果收款账户不是员工本人账户，需要财务经理审批。
- 报销付款用途必须填写具体费用类型。

### 3.3 金额审批规则

| 报销金额 | 审批流程 |
|---|---|
| 小于等于 1000 元 | 部门负责人审批 |
| 大于 1000 元且小于等于 10000 元 | 部门负责人 + 财务主管审批 |
| 大于 10000 元且小于等于 50000 元 | 部门负责人 + 财务主管 + 财务经理审批 |
| 大于 50000 元 | 部门负责人 + 财务主管 + 财务经理 + 财务总监审批 |

### 3.4 特殊规则

- 差旅报销超过差旅标准，需要行政负责人审批。
- 业务招待费超过 5000 元，需要分管副总审批。
- 单张发票金额超过 10000 元，需要财务复核。
- 跨月报销超过 60 天，需要财务经理审批。
- 无票报销需要财务总监审批。

## 4. 工资发放审批规则

默认流程：

人事提交工资表 → 财务主管复核 → 财务经理审批 → 财务总监审批 → 出纳发送银行

规则：

- 工资发放必须使用工资专用户或基本户。
- 工资发放不允许使用采购付款审批流。
- 月度工资至少需要财务主管和财务经理审批。
- 奖金单批次超过 1000000 元时，需要财务总监审批。
- 高管薪酬任意金额均需要总经理审批。
- 工资批次中存在外部人员时，需要标记为劳务费。
- 工资发放审批通过后，不允许修改工资明细。

## 5. 采购付款审批规则

### 5.1 基础规则

- 采购付款必须关联采购合同或采购订单。
- 收款方必须为供应商档案中的有效供应商。
- 付款金额不得超过合同未付金额。
- 如果付款金额超过合同金额，需要采购负责人和财务总监审批。
- 供应商账户变更后首次付款，需要财务复核。

### 5.2 金额审批规则

| 付款金额 | 审批流程 |
|---|---|
| 小于等于 50000 元 | 采购负责人 + 财务主管 |
| 大于 50000 元且小于等于 500000 元 | 采购负责人 + 财务主管 + 财务经理 |
| 大于 500000 元且小于等于 2000000 元 | 采购负责人 + 财务经理 + 财务总监 |
| 大于 2000000 元 | 采购负责人 + 财务经理 + 财务总监 + 总经理 |

## 6. 备用金审批规则

备用金适用于员工临时借款、项目周转、差旅预支等场景。

规则：

- 申请人必须为企业在职员工。
- 单人未核销备用金不得超过 2 笔。
- 个人备用金余额不得超过 20000 元。
- 备用金必须在规定期限内核销。
- 超期未核销时，系统限制再次申请。

审批规则：

| 备用金金额 | 审批流程 |
|---|---|
| 小于等于 5000 元 | 部门负责人审批 |
| 大于 5000 元且小于等于 20000 元 | 部门负责人 + 财务主管审批 |
| 大于 20000 元 | 部门负责人 + 财务主管 + 财务经理审批 |

## 7. 税费缴纳审批规则

税费缴纳适用于企业增值税、企业所得税、个人所得税、社保公积金等缴纳场景。

规则：

- 税费缴纳必须关联税务申报记录。
- 收款方必须为税务机关、社保机构或公积金中心。
- 税费缴纳通常不允许修改收款账户。
- 税费缴纳金额超过 1000000 元时，需要财务总监审批。
- 税费缴纳必须保留缴款凭证。

审批流程：

税务岗提交 → 财务主管审批 → 财务经理审批 → 出纳付款

## 8. 融资还款审批规则

融资还款适用于银行贷款还本、付息、融资租赁还款等。

规则：

- 融资还款必须关联融资合同。
- 还款金额不得超过当期应还金额。
- 提前还款需要资金负责人审批。
- 逾期还款需要财务总监审批。
- 融资还款成功后，系统自动更新融资台账。

审批流程：

融资专员提交 → 资金经理审批 → 财务总监审批 → 出纳付款

## 9. 内部资金调拨审批规则

内部资金调拨适用于集团内部账户之间的资金划转。

规则：

- 必须明确调出账户和调入账户。
- 调出账户和调入账户必须属于同一集团。
- 内部调拨不允许转入外部供应商账户。
- 单笔内部调拨小于等于 1000000 元时，可走简化审批。
- 单笔内部调拨超过 1000000 元时，需要资金经理审批。
- 跨法人主体调拨需要财务总监审批。

审批流程：

资金专员提交 → 资金经理审批 → 财务总监审批

## 10. 高风险付款识别规则

以下情况被识别为高风险付款：

- 收款账户为首次付款账户。
- 收款户名与供应商名称不一致。
- 付款金额超过近 90 天平均付款金额 3 倍。
- 非工作时间提交大额付款。
- 付款用途为其他或备注不清晰。
- 付款账户余额接近下限。
- 同一收款账户在短时间内收到多笔大额付款。
- 付款金额为整数大额，例如 1000000 元、5000000 元。
- 跨境付款或外币付款。
- 审批人和经办人为同一人。

处理规则：

1. 系统自动标记风险等级。
2. 经办人必须补充付款说明。
3. 财务经理必须复核。
4. 严重风险需要财务总监审批。
5. 系统记录风险识别原因。

## 11. 预算控制规则

- 有预算项目的付款必须占用预算。
- 预算不足时不允许直接付款。
- 超预算付款需要预算负责人审批。
- 预算占用在付款申请提交时发生。
- 付款驳回或撤销时释放预算。
- 付款成功后预算占用转为实际支出。

## 12. 常见问答

### 问：为什么采购付款需要总经理审批？

答：如果采购付款金额超过 2000000 元，或者付款金额超过合同金额，系统会自动增加高级审批节点。

### 问：报销付款可以付给别人吗？

答：原则上报销款应支付给员工本人账户。如果收款账户不是员工本人账户，需要财务经理审批。

### 问：备用金申请为什么被限制？

答：如果申请人存在未核销备用金，且未核销笔数超过 2 笔，或个人备用金余额超过 20000 元，系统会限制新的备用金申请。
