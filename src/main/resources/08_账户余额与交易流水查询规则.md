# 账户余额与交易流水查询规则

## 1. 适用范围

本文档适用于财资管理系统中的账户余额查询、可用余额查询、交易流水查询、流水同步、余额缓存等场景。

## 2. 账户余额类型

系统展示的余额包括：

| 余额类型 | 说明 |
|---|---|
| 账面余额 | 银行账户当前账面资金余额 |
| 可用余额 | 当前可用于付款的金额 |
| 冻结余额 | 被银行或系统冻结的金额 |
| 在途余额 | 已提交但未完成清算的金额 |
| 资金池余额 | 归集或下拨后的集团可视余额 |

## 3. 余额查询规则

- 用户只能查询已授权账户的余额。
- 余额查询需要调用对应银行的余额查询接口。
- 查询结果需要记录查询时间。
- 对于高频查询账户，系统可以缓存余额结果。
- 余额缓存有效期默认为 60 秒。
- 付款发送银行前，必须实时查询可用余额。
- 如果银行余额接口异常，系统展示最近一次成功查询结果，并标记数据时间。

## 4. 可用余额校验规则

付款发送银行前，系统需要校验可用余额。

规则：

- 可用余额必须大于等于付款金额。
- 如果存在手续费，需同时覆盖手续费。
- 如果账户设置最低留存金额，付款后余额不得低于最低留存金额。
- 如果余额不足，不允许发送银行。
- 余额不足时，审批状态不变，但发送银行操作失败。

## 5. 交易流水查询规则

交易流水用于展示账户的资金流入和流出记录。

规则：

- 支持按账户、日期、金额、收支方向、对方户名查询。
- 单次查询时间范围最多 31 天。
- 默认查询最近 7 天流水。
- 流水查询结果以银行返回为准。
- 不同银行流水同步时效可能不同。
- 当日流水可能存在延迟。

## 6. 流水同步规则

系统支持自动同步银行流水。

规则：

- 默认每日 02:00 同步前一日流水。
- 重点账户支持每 30 分钟增量同步。
- 如果银行接口异常，系统自动重试 3 次。
- 重试失败后，生成流水同步异常任务。
- 流水同步完成后，系统按银行流水号去重。

## 7. 流水去重规则

流水去重字段包括：

- 银行流水号
- 付款账号
- 收款账号
- 交易金额
- 交易时间
- 收支方向

规则：

- 如果银行流水号存在，则优先使用银行流水号去重。
- 如果银行流水号为空，则使用账号、金额、时间、方向组合去重。
- 重复流水不允许重复入账。
- 流水修正需要记录操作日志。

## 8. 常见问答

### 问：为什么可用余额和账面余额不一致？

答：账面余额表示账户当前账面资金，可用余额表示当前可用于付款的金额。冻结金额、在途金额、最低留存金额等都会导致两者不一致。

### 问：为什么刚发生的交易流水查不到？

答：不同银行流水同步存在延迟，当日流水可能不会立即返回。可以稍后重试，或通过交易状态查询查看付款结果。

### 问：余额接口异常时系统展示的余额可靠吗？

答：如果银行余额接口异常，系统可能展示最近一次成功查询结果，并标记查询时间。付款发送前仍需要实时校验余额。
