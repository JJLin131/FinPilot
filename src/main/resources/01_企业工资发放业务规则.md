# 企业工资发放业务规则

## 1. 适用范围

本文档适用于财资管理系统中的工资发放、奖金发放、补贴发放、劳务费发放等业务场景。系统支持企业通过银企直连渠道向员工个人账户批量发放款项。

## 2. 业务流程

工资发放的一般流程如下：

1. 经办人创建工资发放单。
2. 上传工资明细文件。
3. 系统校验收款人姓名、银行卡号、开户银行、发放金额等字段。
4. 经办人提交审批。
5. 系统根据金额、发放类型、付款账户匹配审批流。
6. 审批通过后，出纳或系统自动调用银行代发接口。
7. 银行返回受理结果。
8. 系统定时查询最终处理结果。
9. 发放成功后支持下载电子回单和结果明细。

## 3. 工资发放类型

### 3.1 普通工资

普通工资适用于企业每月固定薪资发放。

规则：

- 必须使用工资发放模板。
- 单批次最多支持 5000 笔明细。
- 单笔金额不得超过 500000 元。
- 单批次总金额不得超过企业配置的工资发放限额。
- 普通工资至少需要财务主管和财务经理审批。
- 工资发放成功后，可下载批量处理结果文件。

### 3.2 奖金发放

奖金发放适用于年终奖、绩效奖金、项目奖金等场景。

规则：

- 奖金发放需要填写奖金类型。
- 单笔奖金超过 100000 元时，需要财务总监审批。
- 单批次奖金总额超过 1000000 元时，需要总经理审批。
- 奖金发放支持预约发放。
- 预约日期不得超过当前日期后 30 天。

### 3.3 补贴发放

补贴发放适用于餐补、交通补贴、通讯补贴、差旅补贴等场景。

规则：

- 单批次补贴总额小于等于 50000 元时，可使用简化审批流。
- 简化审批流为：经办人提交 → 财务经理审批 → 银行发送。
- 补贴发放可以按部门拆分批次。
- 补贴发放成功后，系统自动生成发放明细报表。

### 3.4 劳务费发放

劳务费发放适用于向外部顾问、临时人员、兼职人员支付劳务费用。

规则：

- 劳务费收款人必须维护证件号码或纳税识别信息。
- 单笔劳务费超过 800 元时，系统提示可能涉及个税申报。
- 劳务费发放必须经过业务部门负责人、财务经理、税务岗审批。
- 劳务费发放不允许使用普通工资模板。

## 4. 工资明细文件字段

工资明细文件必须包含以下字段：

| 字段 | 是否必填 | 说明 |
|---|---|---|
| 员工姓名 | 是 | 必须与银行卡开户姓名一致 |
| 银行卡号 | 是 | 只能包含数字 |
| 开户银行 | 是 | 例如工商银行、建设银行、招商银行、杭州银行 |
| 开户支行 | 否 | 跨行代发建议填写 |
| 发放金额 | 是 | 必须大于 0，最多两位小数 |
| 证件号码 | 否 | 劳务费发放时必填 |
| 备注 | 否 | 最多 100 个字符 |

## 5. 文件校验规则

- 银行卡号长度必须在 12 到 30 位之间。
- 发放金额必须大于 0。
- 发放金额最多保留两位小数。
- 员工姓名不能为空。
- 同一批次内不允许出现完全重复的银行卡号、姓名和金额记录。
- 文件合计金额必须等于页面填写的总金额。
- 如果文件存在错误明细，则不允许提交审批。
- 企业可配置是否允许部分有效明细提交。

## 6. 审批规则

### 6.1 默认审批流

普通工资默认审批流：

经办人提交 → 财务主管审批 → 财务经理审批 → 出纳复核 → 银行发送

### 6.2 按金额审批

| 单批次总金额 | 审批规则 |
|---|---|
| 小于等于 50000 元 | 财务主管审批 |
| 大于 50000 元且小于等于 500000 元 | 财务主管 + 财务经理审批 |
| 大于 500000 元且小于等于 2000000 元 | 财务主管 + 财务经理 + 财务总监审批 |
| 大于 2000000 元 | 财务主管 + 财务经理 + 财务总监 + 总经理审批 |

## 7. 状态说明

| 状态 | 含义 |
|---|---|
| 待提交 | 工资发放单已创建但未提交 |
| 审批中 | 正在进行审批 |
| 审批驳回 | 审批人拒绝申请 |
| 待发送银行 | 审批通过，等待调用银行 |
| 银行处理中 | 银行已受理，尚未返回最终结果 |
| 部分成功 | 部分明细成功，部分失败 |
| 全部成功 | 所有明细发放成功 |
| 全部失败 | 所有明细发放失败 |
| 已撤销 | 发放单已撤销 |

## 8. 常见失败原因

- 收款人姓名与银行卡开户姓名不一致。
- 银行卡号错误。
- 收款账户状态异常。
- 企业付款账户余额不足。
- 超过企业单笔或单日支付限额。
- 银行系统维护。
- 跨行清算通道暂不可用。
- 工资文件格式不符合模板要求。

## 9. 常见问答

### 问：工资发放部分成功怎么办？

答：用户可以下载失败明细文件，查看失败原因，修改后重新发起补发。已经成功的明细不需要重复发放。

### 问：工资发放可以撤销吗？

答：如果发放单处于待提交、审批中、待发送银行状态，可以撤销。如果已经进入银行处理中，通常不允许撤销。

### 问：工资发放成功后在哪里下载回单？

答：进入工资发放详情页，在批次状态为全部成功或部分成功后，可以下载回单或结果文件。
