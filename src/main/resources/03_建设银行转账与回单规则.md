# 建设银行转账与电子回单规则

## 1. 适用范围

本文档适用于财资管理系统通过建设银行银企直连渠道发起的单笔转账、批量转账、工资代发、余额查询、流水查询、电子回单下载等业务。

## 2. 支持业务

建设银行渠道支持以下业务：

- 单笔转账
- 批量转账
- 同行转账
- 跨行转账
- 工资代发
- 账户余额查询
- 交易流水查询
- 交易状态查询
- 电子回单下载
- 预约转账

## 3. 转账规则

### 3.1 单笔转账

规则：

- 单笔转账金额上限默认为 3000000 元。
- 支持同行和跨行转账。
- 转账用途不能为空。
- 跨行转账需要填写收款银行联行号或开户支行。
- 非工作日提交的跨行转账可能顺延处理。

### 3.2 批量转账

规则：

- 单批次最多支持 2000 笔。
- 批量转账文件必须使用系统标准模板。
- 系统需要校验户名、账号、金额、开户行等字段。
- 批量转账提交后，建设银行可能先返回已受理状态。
- 已受理不代表交易成功。

### 3.3 工资代发

规则：

- 工资代发单批次最多支持 4000 笔。
- 工资代发需要使用建设银行代发工资接口。
- 工资代发成功后，可下载汇总回单和明细回单。
- 工资代发的回单通常在 T+1 日生成。

### 3.4 预约转账

规则：

- 支持预约转账。
- 预约日期最多可选择当前日期后 15 天内。
- 预约转账在执行前可以撤销。
- 预约转账进入银行处理后不可撤销。

## 4. 状态查询规则

建设银行交易可能返回以下状态：

| 银行状态 | 系统状态 | 说明 |
|---|---|---|
| 已受理 | 银行处理中 | 银行收到请求，但未完成处理 |
| 交易成功 | 成功 | 资金划转成功 |
| 交易失败 | 失败 | 银行处理失败 |
| 交易不存在 | 银行处理中 | 可能存在银行数据同步延迟 |
| 待清算 | 银行处理中 | 跨行交易等待清算 |

查询规则：

- 如果银行返回已受理，系统需要继续查询最终状态。
- 如果银行返回交易不存在，应间隔 3 分钟后重试。
- 建议每 5 分钟查询一次，最多查询 12 次。
- 跨行交易处于待清算时，不允许重复提交。
- 状态未成功前，不允许下载回单。

## 5. 电子回单规则

建设银行电子回单规则：

- 电子回单通常在交易成功后 T+1 日生成。
- 当日交易可能无法立即下载回单。
- 回单文件格式支持 PDF 和 OFD。
- 单笔转账支持下载单笔回单。
- 批量转账支持下载汇总回单和明细回单。
- 如果回单未生成，系统提示“银行暂未生成回单，请稍后重试”。
- 失败交易不生成电子回单。

## 6. 回单下载参数

下载建设银行电子回单时，系统需要提供以下参数：

| 参数 | 是否必填 | 说明 |
|---|---|---|
| 企业编号 | 是 | 建设银行企业客户编号 |
| 付款账号 | 是 | 企业付款账户 |
| 交易日期 | 是 | 交易日期 |
| 银行流水号 | 是 | 银行返回的交易流水 |
| 回单编号 | 否 | 若银行返回回单编号则传入 |
| 文件格式 | 否 | PDF 或 OFD |

## 7. 异常处理

### 7.1 已受理状态处理

如果银行返回已受理，系统不得将交易标记为成功。系统应继续定时查询，直到返回交易成功或交易失败。

### 7.2 交易不存在处理

如果银行返回交易不存在，可能是银行数据尚未同步。系统应间隔 3 分钟后重试，不应立即标记为失败。

### 7.3 回单 T+1 生成

如果用户当天下载建设银行回单失败，系统应提示建设银行回单可能需要 T+1 日生成。

## 8. 常见问答

### 问：建设银行已受理是不是代表转账成功？

答：不是。已受理只表示银行收到交易请求，最终结果需要继续查询。

### 问：建设银行当天交易为什么不能马上下载回单？

答：建设银行部分电子回单需要 T+1 日生成，当日交易可能暂时无法下载回单。

### 问：建设银行返回交易不存在怎么办？

答：系统应间隔 3 分钟后重试，因为可能存在银行数据同步延迟。
