# 杭州银行转账与电子回单规则

## 1. 适用范围

本文档适用于财资管理系统通过杭州银行银企直连渠道发起的转账支付、账户余额查询、交易流水查询、代发工资、电子回单下载等业务。

## 2. 支持业务

杭州银行渠道支持以下业务：

- 单笔转账
- 批量转账
- 企业内部账户转账
- 同行转账
- 跨行转账
- 代发工资
- 账户余额查询
- 交易流水查询
- 交易状态查询
- 电子回单下载

## 3. 转账规则

### 3.1 单笔转账

规则：

- 单笔转账支持企业内部账户、同行账户和跨行账户。
- 单笔金额上限默认为 1000000 元。
- 工作日 09:00 至 16:30 提交的交易优先处理。
- 16:30 后提交的跨行交易可能进入次日处理队列。
- 转账用途不能为空。
- 跨行转账需要填写收款银行名称。

### 3.2 批量转账

规则：

- 批量转账单批次最多支持 1000 笔。
- 批量明细必须包含收款户名、收款账号、收款银行、金额和用途。
- 任意明细校验失败时，默认不允许提交。
- 企业可以配置是否允许有效明细继续提交。
- 批量转账提交后，银行返回批次受理流水号。

### 3.3 代发工资

规则：

- 代发工资单批次最多支持 3000 笔。
- 代发工资必须经过工资发放审批流。
- 代发工资需要保存银行批次流水号。
- 批次全部完成后可以下载工资发放结果文件。
- 工资代发批次回单通常在批次全部完成后生成。

## 4. 状态查询规则

杭州银行交易可能返回以下状态：

| 银行状态 | 系统状态 | 说明 |
|---|---|---|
| ACCEPT | 银行处理中 | 银行已受理 |
| SUCCESS | 成功 | 交易成功 |
| FAIL | 失败 | 交易失败 |
| PROCESSING | 银行处理中 | 银行处理中 |
| TIMEOUT | 银行处理中 | 银行响应超时，需要继续查询 |

查询规则：

- 转账提交后，银行返回受理流水号。
- 系统必须保存银行流水号，用于后续状态查询和回单下载。
- 如果银行返回处理中，系统每 5 分钟自动查询一次。
- 查询超过 10 次仍无最终结果时，状态保持为银行处理中。
- TIMEOUT 不代表失败，需要继续查询最终状态。
- 未获取最终成功状态前，不允许下载回单。

## 5. 电子回单规则

杭州银行电子回单规则：

- 电子回单下载必须传入银行流水号。
- 转账成功后通常 30 分钟内生成回单。
- 工资代发批次回单通常在批次全部完成后生成。
- 回单文件格式支持 PDF。
- 回单下载失败时，系统允许用户手动重试。
- 失败交易不生成电子回单。
- 银行处理中交易不允许下载电子回单。

## 6. 回单下载参数

下载杭州银行电子回单时，系统需要提供以下参数：

| 参数 | 是否必填 | 说明 |
|---|---|---|
| 企业客户号 | 是 | 杭州银行分配的企业编号 |
| 付款账号 | 是 | 企业付款账户 |
| 银行流水号 | 是 | 转账或代发成功后的银行流水 |
| 交易日期 | 是 | 交易发生日期 |
| 交易金额 | 是 | 付款金额 |
| 批次号 | 否 | 批量业务或代发业务需要传入 |

## 7. 异常处理

### 7.1 TIMEOUT 状态处理

如果杭州银行返回 TIMEOUT，系统不得直接判定失败。系统应继续使用银行流水号查询最终状态。

### 7.2 银行流水号缺失

如果提交成功但未保存银行流水号，系统将无法进行状态查询和回单下载。此类数据应进入人工核查队列。

### 7.3 回单下载失败

如果回单下载失败，系统应：

1. 记录失败原因。
2. 判断交易是否成功。
3. 如果交易成功但回单未生成，提示稍后重试。
4. 如果银行接口异常，允许用户手动重试。
5. 如果多次失败，进入人工处理。

## 8. 常见问答

### 问：杭州银行转账超时是否代表失败？

答：不是。TIMEOUT 或接口超时不代表交易失败，系统需要继续查询最终交易状态。

### 问：杭州银行回单下载需要什么条件？

答：交易必须成功，并且系统必须保存银行流水号。回单通常在交易成功后 30 分钟内生成。

### 问：杭州银行代发工资回单什么时候可以下载？

答：代发工资批次通常需要等待批次全部处理完成后才能下载回单或结果文件。
